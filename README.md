# Практична робота: Створення автоматизованого тесту за допомогою штучного інтелекту та публікація коду на GitHub

* **Вебсайт, який тестувався:** [https://cnu.edu.ua/](https://cnu.edu.ua/) (Карпатський національний університет імені Василя Стефаника)
* **Використаний інструмент ШІ:** Google Gemini

## Короткий опис трьох автоматизованих перевірок
1. **Перевірка відкриття сайту та заголовка сторінки:** скрипт відкриває головну сторінку університету та перевіряє, що атрибут `<title>` («Карпатський національний університет імені Василя Стефаника») успішно завантажився і не є порожнім.
2. **Перевірка наявності елементів інтерфейсу:** скрипт перевіряє видимість основних елементів навігації та логотипа (`nav, img`) на сторінці.
3. **Перевірка переходу на іншу сторінку:** скрипт знаходить пункт меню «Підрозділи», виконує клік та перевіряє, що URL-адреса змінилася на внутрішню сторінку сайту (`https://cnu.edu.ua/?page_id=647`).

## Інструкція із запуску тесту
1. Встановіть [Node.js](https://nodejs.org) на комп'ютер.
2. Завантажте файл `test-cnu.js` із цього репозиторію у нову папку.
3. Відкрийте термінал у папці проєкту та встановіть бібліотеку Playwright і браузер Chromium:
   ```bash
   npm init -y
   npm install playwright
   npx playwright install chromium
   ```
4. Запустіть автоматизований тест командою:
   ```bash
   node test-cnu.js
   ```
